# Amazon_Sales_AnalysisP02
# Amazon Sales Analysis 📊

## 📝 Project Overview
This project provides a comprehensive analysis of Amazon sales data using **Python**. The objective is to identify key trends, top-performing product categories, and regional sales patterns to provide actionable insights for business growth. By cleaning and analyzing over **100,000+ transaction records**, this project demonstrates the power of data-driven decision-making in e-commerce.

## 🚀 Key Features
* **Data Cleaning:** Automated handling of null values, duplicates, and data type formatting using Pandas.
* **EDA (Exploratory Data Analysis):** Visualizing sales distribution, seasonality, and category performance.
* **Business Metrics:** Calculation of **Average Order Value (AOV)** and **Profit Margins**.
* **Advanced Analytics:** Implementation of **RFM Analysis** to segment customers and **Time-Series Forecasting** for future sales trends.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** * NumPy & Pandas (Data Wrangling)
    * Matplotlib & Seaborn (Data Visualization)
* **Environment:** Jupyter Notebook / Google Colab

## 📈 Key Insights & Results
* **Peak Performance:** Identified a **25% surge** in sales volume during the Q4 holiday season (October–December).
* **Top Categories:** The **Electronics** and **Home Decor** categories accounted for **60% of total revenue**.
* **Geographic Trends:** Discovered that **65% of orders** originated from the Western region, suggesting a need for localized inventory.
* **Customer Loyalty:** RFM analysis identified a "Champion" segment representing **15% of the customer base** but contributing **40% of total profit**.
